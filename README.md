# Проверка метода замораживания

- [Статья по шаблону XI Пермской конференции по ИИ](Статья/Статья.pdf)
- [Эссе по восьми лабораторным работам](Эссе/Эссе_ЛР1–ЛР8.pdf)
- [Итоговый проект Нейросимулятора](Проекты/final_GUI.np4)

Степан Козлов, НИУ ВШЭ – Пермь, РИС-24-1.

В папке «Данные» лежат исходная учебная книга, фиксированное разбиение по группам имён и карта сценариев. «Проекты» содержит входные NP4 и проекты, сохранённые в Нейросимуляторе 5. «Результаты» содержит анализ данных, метрики и ответы. «Графики» содержит сравнение фонов.

1. Установить зависимости командой `python -m pip install -r requirements.txt`.
2. Запустить `python Код/prepare_study.py` для исходных конфигураций. Можно использовать уже приложенные h2_input, h3_input и h5_input.
3. Открыть каждый входной NP4 в предоставленном Нейросимуляторе 5. На вкладке «Обучение» нажать «Обучить заново». На вкладке «Проверка» нажать «Вычислить» и сохранить проект как h2_validated.np4, h3_validated.np4 или h5_validated.np4 соответственно.
4. Запустить `python Код/compare.py`. Он сравнит валидацию и подготовит test_freeze_input.np4 с весами выбранной сети.
5. Открыть test_freeze_input.np4. На вкладках «Проверка» и «Прогноз» нажать «Вычислить», затем сохранить как final_GUI.np4. Обучение на этом шаге не запускать.
6. Запустить `python Код/analyze.py`. Скрипт сверит входы и веса, рассчитает метрики из сохранённых ответов и построит график.

Наибольшая точность валидации у 7–5–1, 8/8. На тесте 4/5. Все 860 сценариев вычислены в программе. Исходный код Нейросимулятора в эту работу не входит.
